# 扫描输出归档

`YYYY-MM/` 按文件名中的 UTC 年月保存归档后的 `ai_value_scan_*` 文件。一组相同时间戳的文件属于一次扫描，可包含主排序 CSV、按类别的 CSV、动量和行业清单、研究池、诊断、网络统计及 Markdown 运行报告。

例如 `2026-10/` 保存文件名时间为 2026 年 10 月的扫描结果。仍在 `outputs/` 根目录的近期文件保持原位置，供按根目录查找最新结果的工具使用。当前日期的正式决策和可读日报分别见 [decisions/](../decisions/README.md) 和 [reports/](../reports/README.md)。

部分历史回测工具只搜索指定目录的直接子文件。需要读取某个月的归档时，可将回测的 `--outputs-dir` 指向对应月份目录。目录约定和整理命令见[项目 README](../../README.md#81-目录约定与每月整理)。
