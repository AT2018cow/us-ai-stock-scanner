# 观察期预注册协议（Observation Protocol）

> 状态：生效（两风格架构，观察起始日 2026-09-24）
> 依据：style_evolution_history.md Phase 4 判定 + 用户决策（两风格并行观察、不做权重、推迟组合决策）

## 1. 架构与原则

- **两个观察对象**：`risk_on`（双动量进攻）与 `risk_off`（低吸防守 + 深度熊市 SMA200 熔断）。
  balanced 已归档（`configs/archive/`，与 risk_off 收益相关 0.999，冗余）。
- **不做权重、不做轮动、不做组合**：每次观察周期只是独立记录两风格的表现。
- 决策推迟：观察数据积累后再回答"如何使用这两条腿"。

## 2. 观察周期与执行

- **每期命令**：`.venv/bin/python scripts/observation_scan.py`（先 risk_off 后 risk_on，各自完整扫描 + 归档 watchlist 快照）。
- 建议频率：与原扫描节奏一致（每次想看市场时跑一次；至少每周一期）。
- 观察最短时长：**6 个月**（少于该时长不做架构性改动，防止对噪音过度反应）。

## 3. 预注册指标（每期记录，防确认偏误）

对每个风格分别记录：

| 指标 | 来源 | 判定基准 |
|---|---|---|
| **特征镜像性** | low_value 清单的 drawdown/price_to_sma200 分布（risk_off）；momentum 清单的 r20/52w 位置分布（risk_on） | risk_off 选股应满足"有回撤深度、200 日线附近"；risk_on 选股应满足"站上 200 日线、近 52 周高位"——分布漂移即触发审查 |
| 信号数量 | report 的 shortlist/triage 计数 | 长期 0 信号（连续 3 期）= 风格失效信号，触发审查 |
| **regime 标记** | report 网络日志 / events 的 `benchmark_trailing_60d` | 记录当期 QQQ regime；两风格在 up/down 各自的纸面表现分开归档 |
| **纸面收益（60d + 120d 前瞻）** | 下期观察时回填上期 shortlist 的 60 天与 120 天实际收益 | **双期限记录**（60d 与 120d）。120d 是体系信号最强的期限（截面 IC t=3~7），60d 保留作为对照。判定一律用"平均超额 vs QQQ + 超额胜率"双指标，不用绝对胜率（牛市虚高）。risk_on 目标：up 段正超额；risk_off 目标：回调/修复段正超额。**不与 QQQ 全周期比较**（risk_off 基准定位为绝对收益型） |
| 两风格重叠度 | 两 shortlist 的标的交集 | 若持续 >70%，说明风格分化失效，触发审查 |

## 4. 预声明的审查触发条件

1. 特征镜像性破坏（选股特征分布离开设计区域）；
2. 连续 3 期零信号；
3. 两风格重叠度持续 >70%；
4. risk_off 的 SMA200 熔断实际触发后（罕见事件），人工复盘其行为是否符合设计。

**未触发审查条件（不得凭单期直觉改动）**：某期纸面收益为负、某期跑输 QQQ、某期某风格空仓。

## 5. 观察期结束后的决策问题（预先列出，不作预答）

1. 两条腿的使用方式（观察各自的绝对表现与相关性变化后决定）；
2. risk_off 的动量熔断是否有必要（Phase 4 模拟证明动量熔断会砍掉 down 期收益——观察期用真实数据继续检验）；
3. 是否恢复三风格或引入新的第三风格（观察数据回答）。

**主指标：平均超额 vs QQQ（每持有期，base 场景，valid 事件）**

|---|---|---|---|
| low_value | 20d | -0.68pp（超额胜率 47.5%） | +0.03pp（57.5%） |
| low_value | 60d | -1.29pp（41.0%） | -0.28pp（51.3%） |
| low_value | 120d | -3.89pp（25.0%） | **+4.94pp（50.0%）** |
| momentum | 20d | +0.07pp（60.0%） | +0.21pp（60.0%） |
| momentum | 60d | -0.49pp（41.0%） | -0.31pp（43.6%） |
| momentum | 120d | **+0.95pp（超额胜率仅 30.6%）** | **+1.16pp（30.6%）** |

**语义警示**：绝对胜率（组合上涨比例）在牛市里普遍 86-92%，**不是**跑赢基准的证据；
判定一律以"平均超额 + 超额胜率"双指标为准。momentum 120d 的正均值由少数大赢家
驱动（正偏尾部），超额胜率仅 ~31%。

**设计目标对照**：risk_off 定位为"绝对收益 + 深熊熔断保命"（QQQ SMA200 下方
空仓，2022 全年 0 信号已核实），**不以跑赢 QQQ 为目标**；risk_on 定位为
"上涨段正超额"（120d +4.94pp 是其设计目标的历史印证，但超额胜率仅 50%）。

两风格 low_value 60d 收益相关性（2023-2026 月度重叠）：约 0.47；
120d 相关性约 0.06（互补性随持有期拉长而增强）。
