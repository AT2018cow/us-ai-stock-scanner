## 1. 修复与运行行为

旧收益函数按各股票已有行数决定退出日。股票中途缺一天，退出便可能比QQQ晚一天；下一session缺失也可能被数日后的开盘替代。新函数统一使用交易所日历：下一session开盘入场、第N个session收盘退出，中间缺行不改变退出日，缺少任一端点明确不可用。

实际IEX样例：EOG/KMI/SCCO在2022-03-08缺行，QQQ不缺。2022-02-28信号的60d共同入场为2022-03-01，退出为2022-05-24。直接查询原始IEX验证修复后不再顺延，见[根因记录](iex_misalignment_root_cause.json)。SIP也不能假设永远不缺行：DRS和NBIS的受影响标签已按同一规则重建。DRS跨2022-11-23拆股的独立原始价/倍率复算误差约1.1e-16；缺入场日的DRS窗口保持未知，见[独立核验](independent_raw_checks.json)。

正式扫描在美股收盘20分钟后开放，节假日使用最新完整session，半日市按实际收盘时间计算。历史SIP请求显式携带过去的end，排除未完成日线，以目标session的close×volume计算价格/成交额，不调用最新SIP快照。SIP和IEX缓存目录隔离。QQQ缺目标日或拆股接口失败阻断正式输出；个股缺目标日按缺失行情排除，不回退IEX。正式快照/指针失败使正式扫描失败，不能由旧CSV成功掩盖。

盘中监控继续请求IEX，关闭行情缓存；终端和Markdown分别显示IEX临时行情与实际快照来源。旧快照缺少feed证据时标为unspecified，不冒称SIP。显式快照的日期改从记录读取，修复原先把目录名production显示为日期的问题。影子仍复用正式Entry构建器，只读、不修改正式决策。

历史SIP延迟权限与实时SIP权限不同；本账户已有历史权限，真实扫描已成功，无需变更实时订阅。本次20分钟窗口是项目采用的保守运行余量。[Alpaca数据权限说明](https://docs.alpaca.markets/us/docs/market-data-faq)。公司行动查询end为包含边界的日期，继续保留原始行情与计算时拆股调整语义。[Alpaca公司行动接口](https://docs.alpaca.markets/us/reference/corporateactions-1)。
