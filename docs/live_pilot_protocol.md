# 实盘试点协议（Live Pilot Protocol，预注册）

> 状态：生效（2026-09-27）
> 定位：**受控实盘实验**——截面排名能力已被大样本验证（IC t=3~7），但组合级
> 超额未达统计显著（risk_on low_value 120d +4.94pp，t=1.82）。本协议用分级
> 放量在真实市场中检验体系，观察期协议（two_style_observation_protocol.md）
> 降级为**并行监控**，不再是实盘前置门槛。

## 1. 证据现状（预注册，防止事后合理化）

| 证据 | 数字 | 强度 |
|---|---|---|
| 截面排名 IC（120d，2021-2026，47-48 日期） | risk_off low_value +0.069 (t=4.9)；momentum +0.081 (t=7.2) | **强** |
| risk_on low_value 120d 组合超额 | +4.94pp/期，n=36，超额胜率 50% | 弱（t=1.82） |
| momentum 120d 组合超额 | +0.95~1.16pp/期，超额胜率 31%（尾部驱动） | 弱（t=0.4-0.5） |
| risk_off 持仓期超额 | -3.89pp/期（t=-2.86，显著为负） | 其职责=熔断保护+绝对收益，非跑赢 |
| QQQ 熔断器 | 2022 全年空仓已核实（避开 -18.7%） | 机制有效 |
| 管道质量 | 全总体不变量验证 PASS（I2 零不匹配） | 前置条件 |

**结论表述**：不向自己或他人声称"已证明能赚钱"；准确表述是
"排名有可验证的统计能力，组合兑现能力待实盘检验"。

## 2. 资金分级（不得跳级）

| 阶段 | 资金比例 | 进入条件 | 持续 |
|---|---|---|---|
| P0 纸面 | 0% | 协议签署即开始 | ≥4 周 |
| P1 试点 | 25% | P0 完成 + 首个 cohort 跟踪无异常 + 周验证 PASS | ≥1 个季度（一个完整 120d cohort） |
| P2 半仓 | 50% | P1 首个实盘 cohort 120d 超额 ≥ -3pp（不要求为正——样本太小）| ≥1 个季度 |
| P3 全仓 | 100% | P2 两个 cohort 均值超额 > 0 且超额胜率 ≥ 40% | — |

降级规则：任一阶段的最新 cohort 120d 超额 < -8pp，或组合回撤 -15% → 退回上一阶段。

## 3. 交易规则（预注册，不得临场修改）

1. **入场来源**：每期 `observation_scan.py` 的两风格输出 →
   `generate_trade_plan.py` 生成计划。分层权重（2026-09-27 全历史实证，见 §3.1）：
   - low_value：keep 全仓、watch 半仓
   - momentum：research_now / watch_for_pullback 全仓，theme_only / avoid_for_now 半仓，
     **left_side_watch 排除**（120d 组合口径仅 +1.0%、胜率 44%）
2. **入场执行**：次日开盘市价单；不追高（开盘跳空 >5% 放弃该标的）。
3. **持有期**：120 个交易日。每月生成一个新 cohort（滚动，约 1/6 仓位到期）。
4. **主熔断**：QQQ 收盘 < SMA200 → 停止一切新开仓（两风格同守则）；
   恢复条件：QQQ 重新站上 SMA200。
5. **仓位**：单一置信池——跨风格合并后按分层倍数分配（双风格合并仓 = 单风格仓的 2 倍权重），
   单标的 ≤ 总资金 10%，账户恒留 10% 现金。60/40 风格分配仅是观察/监控镜头，不是资金分割
   （早期版本的 per-sleeve 预算在合并仓位上会超支——2026-09-27 已修复并验证：权重求和=90%、
   名义求和=可部署额、单仓≤10%、无重复）。
6. **止损**：单标的 -25%（自入场价）；组合自阶段起点 -15% → 暂停开仓+复盘。
7. **禁止事项**：不加仓摊平、不因单期直觉改配置、不跳过验证周检、
   不使用 drop 标的、熔断期间不"抄底"。

### 3.1 分层权重的实证依据（2021-2026 幸存者数据集，修复后管道）

**low_value keep/watch 区分力**（组合口径，120d 前向收益）：

| 风格 | keep | watch | 差距 | 备注 |
|---|---|---|---|---|
| risk_off | +6.06%（胜率 73.5%） | +3.32%（67.3%） | **+2.7pp** | 稳定有效 |
| risk_on | +17.70%（75.5%） | +9.74%（71.4%） | **+8.0pp** | 60d 个股口径无区分（+2.97% vs +3.01%），优势在 120d 兑现——与持有期设定一致 |

**momentum research priority 区分力**（组合口径，120d；两风格机器相同）：

| priority | 120d 收益 | 胜率 | 权重 |
|---|---|---|---|
| research_now | +13.08% | 63.5% | 1.0x |
| watch_for_pullback | +9.29% | 75.5% | 1.0x |
| avoid_for_now | +8.76% | 69.8% | 0.5x（"avoid" 语义面向 research pool，momentum 语境中不弱） |
| theme_only | +6.25% | 73.6% | 0.5x |
| left_side_watch | +1.05% | 43.8% | **0x 排除** |

**已知死层**：drop tier 在 scored 架构下从不触发（25,972 个 low_value 幸存者中 0 个
drop——soft_pass_rate 单项贡献 composite 0.30，composite 几乎不可能 ≤0.35）。
drop 规则（max_composite_score=0.35）是硬过滤时代的遗产，当前无实际作用；
不改动它（回测 pick 路径引用了 drop 排除，改动需连带研究），仅记录。

## 4. 监控与回滚

- **每周**：`observation_scan.py`（双风格）+ `validate_ttm_population.py`
  （必须 PASS；连续 2 周 FAIL → 暂停新开仓直到修复）
- **每月**：新 cohort 入场；到期 cohort 结算：记录 120d 实际收益、超额 vs QQQ、
  超额胜率更新
- **每季度**：阶段晋级评估（§2 条件）；对照两风格观察协议的审查触发条件
- **回滚触发**：降级规则（§2）+ 管道验证连续失败 + 数据中断（Alpaca/SEC 不可用 >1 周）

| 命令 | 用途 |

| `.venv/bin/python scripts/validate_ttm_population.py` | 全总体数据质量不变量验证（周检） |

## 6. 与观察期协议的关系

- 观察期继续并行运行（零额外成本，积累 PIT 快照与前向收益）；
- 观察期的审查触发条件（镜像性破坏、连续空信号、重叠度 >70%、熔断复盘）
  **同样约束实盘**：触发即暂停新开仓，人工复盘后再恢复；
- 观察数据每季度并入阶段晋级评估；6 个月后可用真前向数据回答
  "组合级超额是否显著"这一开放问题。
