# 价值与回踩选股优化：有界、可归因的历史实验规范

- Date: 2026-11-06
- Status: **v4，用户已批准实施；C的联合得分修订亦已单独批准。研究结果不得自动推广生产。**
- Target Execution Agent: DeepSeek（或用户指定的执行代理）
- Scope: 冻结数据上的离线研究与指定日期快照影子对照。
- 本轮目标：评估选股与固定使用效果的增量，允许得出拒绝或证据不足；不预设必须找到赢家。
- 本版替代v3的七方案同时比较，改为基线核验、三个单因素实验、有条件组合及稳健性验证。

## 1. 研究假设及边界

待检验的三个假设：强趋势中的适度回踩是否值得放宽准入；限制过度延伸是否改善净收益或尾部风险；在既有质量约束内增加现金流与增长排序信号是否改善选股。

不能从单日PAYC/ECL/EOG等案例推断阈值过宽或过严，不能预先将高涨幅称为错误买点、低涨幅称为安全买点。阈值是预注册研究假设，不是已经验证的最优参数。

使用当前候选池的历史近似重放。相对同日候选池的收益差，只回答此近似池内的选择效果，**不能消除幸存者偏差**。退市或未进入当前底单的公司仍然缺失。公司子集、贡献股删除只衡量敏感性，不能证明策略普适。无需构建历史ETF成分数据库。

所有年代均为回溯研究。已有历史被反复查看，重新按日期切分不能使它变成全新OOS。无需等待前向观察才能完成本研究，但结论必须注明回溯证据限制。

## 3. P1：三个独立单因素实验

三个候选均直接相对D0，不相互叠加。Quality评分/分级、Entry评分、Action映射及压缩机制保持基线，只有下表声明的维度变化。记录每次状态翻转和名单替换原因。

### A：强趋势回踩下沿

仅在以下条件同时成立时放宽Entry下沿：

- `price_to_sma200 >= 1.02`
- `sma50_to_sma200 >= 1.00`，按两项价格/均线比值的恒等式计算
- `relative_strength_60d_qqq >= 0`
- 非防御市场：`regime != down`且`benchmark_trend_ok is True`

将SMA50下沿从0.98放宽至0.95，20日收益下沿从−0.03放宽至−0.07。上沿、60日收益、波动、回撤、趋势损坏判断及其他规则全部保留。防御市场及未知市场沿用D0，避免同时测试熊市放宽假设。

这是一个“回踩准入”因素，含两个联合下沿，并非单一参数实验。保持原Entry分数，不强制保底加分；分数不足导致未晋升Priority是有效结果，不能临时修改评分补救。

### B：过度延伸上限

仅对原D0为ENTRY_READY的股票增加上限：`price_to_sma200 <= 1.30`、`price_to_sma50 <= 1.05`、`return_20d <= 0.07`。任一超限改为WATCH_PULLBACK，再通过同一Action映射与排序处理。

不放宽下沿，不改变分数，不将原先INSUFFICIENT_DATA或TREND_DAMAGED改成可入选。单独报告被排除股票的后续收益和名单空缺，衡量错过趋势延续的代价。

### C：现金流与增长排序信号

只调整同一Action优先层内、Quality A/B候选的排序；保留不同Action层之间的优先关系及Top-15压缩合同。使用D0生产排序的联合得分作为P（用户在P0后单独批准的澄清）：`0.60*Quality + 0.40*Entry`，保留Priority层A级加分及原财报窗口/非经营利得扣分；P不是StockDecision.priority整数名次。定义：

- FCF yield和revenue_yoy均有限时：`cash = clip(fcf_yield / 0.08, 0, 1)`，`growth = clip(revenue_yoy / 0.20, 0, 1)`。
- `signal = 0.70 * cash + 0.30 * growth`；若FCF yield <= 0，则signal=0。
- `research_priority = 0.90 * P + 0.10 * signal`。
- 任一输入缺失/非有限时使用`research_priority = 0.90 * P`，即缺证据不获得额外正贡献；单独报告此类覆盖率与名次变化。
- P的范围/方向须在P0验证为适合此线性混合；不符合则停止C并提交修订，不自行重标定。
- 排序并列沿用D0确定性规则。保存原priority与研究priority，不能覆盖canonical决策。

该分数只是研究信号，**不是隐含收益率或预期总回报率**。它仍可能与Quality已有增长项重复，因此结果解释为“额外排序权重的边际效果”。不使用利润/OCF同比的OR硬门槛，避免负基数和转盈被当作正常增长；不把FCF yield视为跨行业完全可比。

本轮不使用新增历史PE/PS成熟度加分，不使用数据集首次出现日期推断上市年龄。未来如研究历史分位可靠性，须依实际有效观测数、跨度、分母有效性及当前720天窗口另定方案；缺少元数据时标记未知，不推断成熟。

## 4. P2：有条件组合与暂缓事项

最多构建一个组合候选：只合并通过第7节初筛的因素，按固定顺序A准入→B延伸限制→C层内排序。至少两个因素通过才组合，零或一个通过则不新增组合。该选择本身属于历史数据驱动的模型选择，不可将组合结果称为独立确认。

只比较组合、参与因素、D0，并计算组合相对最佳单因素的增量；不能遍历全部子集择优。全部初筛候选及失败结果必须保留。

原v3底部反转D2、Quality估值重加权D3、防御市场放宽、Entry甜区重评分以及全天候D6暂缓，不在本次审核通过后自动执行。若本轮有明确证据指向其中某项，再另提方案。反转实验尤其要定义其与TREND_DAMAGED的优先级，禁止用0.85强制分数保底。

## 5. 固定收益、基准与缺失处理合同

- 主指标：60交易日`fixed_usage`相对D0的**同日期配对净收益增量**。
- `fixed_usage`：先生成最终Top-15，仅使用其中PRIORITY_REVIEW且ENTRY_READY的标的，每只1/15，空缺现金收益0；不从榜外补齐。
- `list`：沿用已验收全名单视图的成员/权重合同，并在protocol显式记录，用作辅助解释。
- 主稳健性期限120日，20/252日为辅助；使用原标签的次日入场/期限端点合同、15bps每边成本、拆股调整价格回报，不含分红。不能将重叠持有期均值称为账户CAGR。
- 报告QQQ差距及胜率，不强制打赢QQQ；“接近QQQ”的容忍值尚未获用户确认，不以临时阈值宣告达标。
- 共享Eligible Pool取PIT预筛合格公司；共享AB Pool取D0 Quality A/B公司。各候选自身AB池只能用于内部归因。基准收益须按相同期限、成本合同计算。
- 每个期限先按端点成熟度定义共同日期范围；选股时不得读取未来标签是否可用。选中股票缺标签时不能删除股票后重新等权或补选，也不能静默计0。
- 比较主表仅用D0及全部P1候选固定使用槽位均可评价的共同日期；同时输出全成熟日期数、各方案排除日期/股票及原因。空仓是有效0收益，不是缺失。组合另给与参与因素及D0的共同日期表，不改写P1表。
- Eligible/AB基准存在缺标签时报告覆盖率及可观察子集均值，明确不是完整池收益；完整基准覆盖的共同日期另列。不得因基准缺失悄悄改变主指标日期。
- 为缺失选中收益给出明确假设的悲观/乐观敏感性场景（−100%/+100%，并非严格统计上下界）；结论若依赖缺失处理，归为证据不足。

部署分解：记部署比例为e，已部署股票平均净收益为r，使用收益为e*r。对候选与D0均有部署的日期，报告`min(e_candidate,e_D0)*(r_candidate-r_D0)`作为相同部署比例诊断；分别列出单方/双方空仓日期与其实际贡献。不要靠删去空仓日期美化主结果。

## 6. P3：稳健性与阶段归因

所有P1方案输出基础分段表；较重的子集/阈值检查仅用于通过初筛的因素及组合。

1. 按年、市场状态、四时代（2016–2019、2020–2021、2022、2023–2026）报告日期等权结果；ERA_EQ4仅辅助，它给2022单年与其他多年相同权重。周频压力集独立报告，不与月度合并重复计数。
2. 对月度配对差值使用连续日历月区块重采样，区块长度6个月、2000次、种子61106；共同有效日期掩码随原日历一起重采样，不把中间缺失月份压缩成相邻观测。输出95%区间及有效样本数；12个月区块作为敏感性。公司子集不能替代时间相关性处理。
3. 从排序固定的唯一symbol集合无放回抽取70%（向下取整），200次、种子61106；每次候选、D0及池基准使用同一子集，重新选榜。报告配对增量Mean/Median/P05/P95及Win Share，不把Win Share称为显著性概率。月度60日为必做范围。
4. 按全期60日日期等权使用收益超额贡献确定D0与候选各自Top5（贡献公式、并列规则写入protocol），取并集后对双方同时删股重选。保存各自删除的辅助结果。此为事后集中度压力测试，不是可交易选股规则或去偏证明。
5. 不将“2016存在且2026存续”的BALANCED_COHORT列为验收要求。如提供，标记为未来存续条件下的事后切片，不能证明消除幸存者偏差。
6. 阶段归因：共同D0 AB池→Ready→Priority→最终Top-15→固定使用；列出成员改变、状态改变、排序改变、部署改变。阶段均值差是描述性归因，不冒充因果效应。
7. 阈值邻域只检查初筛通过因素：A的SMA50下沿0.94/0.96；B的SMA50上沿1.04/1.06；C的附加信号权重0.05/0.15（基线priority权重相应为1−该权重）。每次只改此一项，其他值固定；只判断脆弱性，不从邻域选新赢家。组合不额外搜索。
8. 成本压力采用30bps每边，与原15bps每边比较。跨期重复入选/留存仅作操作负担指标，不能据此冒充真实账户换手与成本模拟。

## 7. 预先约定的决策标准（随本文审核，不在看结果后调整）

### 初筛：进入深入验证，不能直接推广

60日共同日期固定使用增量>0、120日同口径增量>=0，且60日日期级使用收益<=−20%的发生率相对D0不增加超过1个百分点。此风险容忍是本方案建议值，需随方案审核确认；不得冒称用户此前已指定。

### 最终分类

- **支持继续推进**：初筛通过；60日配对增量的95%时间区块区间下界>0；四时代至少三个增量>=0；公司子集Win Share vs D0>=70%；共同删除Top5后增量仍>0；成本压力下增量仍>0；规定的两个阈值邻域增量均>=0。120日与周频压力结果及风险变化必须一并披露。
- **仅有风险改善**：净收益未满足上述要求，但重伤或压力期损失改善，明确披露收益和部署代价，不称选股收益提升。
- **证据不足**：均值改善但区间、覆盖、敏感性不支持稳定结论，或P0/关键数据条件不满足。
- **拒绝**：没有改善，或改善依赖明显风险增加、少数公司/时期或错误处理。

这些标准是务实的预注册研究门槛，并非收益保证。P1三个主假设的显著性声明须额外给出基于时间区块的单侧中心化重采样p值及Holm三重比较校正（alpha=0.05）；未通过校正只能称探索性信号。组合、其他期限/分段的显著性不作为独立确认。所有标准均不得触发自动生产推广，推广需用户另行批准。

## 9. 方法依据与v3修订说明

本版删除“完全消除幸存者偏差”“GARP隐含总回报率”“未经验证的高胜率/全天候”等结论；取消用截面首次出现推断上市年龄；将六个混合候选缩减为三个可归因因素，明确暂缓项、风险和不成功退出路径。

方法参考：

- [Value and Momentum Everywhere](https://www.aqr.com/Insights/Research/Journal-Article/Value-and-Momentum-Everywhere?aqrPDF=1)：支持研究价值与动量的组合，不证明本文具体阈值。
- [The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)：多次尝试和历史择优的风险；不能把更高历史收益直接解释为泛化能力。
- 本项目最新纠错验收：`docs/review_followup_20261106/report.md`。
