## 1. 要回答的六个问题

| 层级 | 要回答的问题 | 主要证据 | 不能混淆的结论 |
| --- | --- | --- | --- |
| 候选池 | 有价值的公司能否进入系统？ | 发现覆盖、排除原因、独立参考池 | ETF入选不是公司质量证明 |
| Company Quality | 能否识别经营可靠、现金流持续的公司？ | 当时财务证据、后续经营结果、分行业分层 | 财务质量高不等于买入价格便宜 |
| 估值 | 为这些公司支付的价格是否合理？ | 同质量公司估值分层、盈利敏感性、后续回报 | 低PE不等于便宜，周期高点盈利可能误导 |
| Entry | 等待/确认是否改善回报、风险或操作体验？ | 同股票立即与等待对照、状态分组 | 不同股票Ready/非Ready比较不是纯择时因果证据 |
| Action List | 压缩和排序到15名是否提高选择精度？ | 实际最终名单对照、安全池、随机K、截断归因 | 分数好看不能证明名单有效 |
| 人工使用 | 是否帮助用户更快作出更好的研究决定？ | 前瞻研究日志、纸面对照、人工结果单独记录 | 工具体验改善不能替代净超额收益证据 |

项目成功应分别发布“工程可信”“研究有用”“收益证据”三个结论。没有显著超额时可称研究工具有用，不能称已证明选股alpha；也不能因短期收益不足就认定会计质量识别无用。

## 2. 当前阈值的判断与审查范围

**当前指标选择有可解释的经济逻辑，但具体阈值、权重与交互尚不能整体认定为合理或最优。** 测试通过证明实现符合预期，不能证明阈值有投资收益价值。既有历史研究只能支持其实际覆盖的版本、日期和任务。

### 2.1 先建立有效规则清单

配置与最终决策不是同一套门槛。`scanner.py`将`df`传入`build_stock_decisions`，旧策略列表作为来源信息参与；不能把所有legacy筛选参数直接当作最终Top-15硬门槛。也不能假定旧参数完全没有上游影响。

### 2.3 所有阈值使用同一审查流程

1. **定义正确**：分母非正、单季/TTM、拆股、单位、异常值、缺失与行业适用性。缺失不能伪装优秀。
2. **分布与覆盖**：按决策日和行业看分位数、缺失率、满分/零分比例、临界点密度；异常行业单独标注。
3. **结果分层**：开发数据上预定分箱，比较后续经营、20/60/120d超额和下行风险。分箱本身不能事后调到趋势最好看。
4. **边界对照**：看阈值上下邻近样本是否有连续差异；按同日/行业/规模比较，说明非随机分配，不宣称因果识别。
5. **消融**：一次去除一个非安全规则或支柱，保留其他规则，比较名单成员、收益、风险和研究负担。高相关指标采用成组消融；消融研究不关闭生产数据安全门。
6. **局部敏感性**：只预登记少量有经济含义的相邻值。例如12%上限可诊断10%/12%/14%，但这仅是研究网格示例，不是新推荐值。不做所有参数笛卡尔积搜索。
7. **名单传导**：必须列出改变的Top-15成员、Top16–30的机会成本、风险状态、换手、集中度。不换人的参数不优先优化。
8. **独立验证与处置**：结论只能为保留、改为提示/软评分、针对已验证业务模式修订、删除冗余、证据不足。修改须再过完整链路验收。

数据完整性、未来数据和无效算术属于正确性底线，不因放松后历史收益较高而优化掉。金融/保险/REIT等在专门会计语义验证前不强行统一评级。

## 3. 证据体系：回测必要，但不能单独完成证明

### 3.1 三套互补证据

**历史决策截面研究**：主要回答指标、分层、排序和失败机制。使用已有冻结数据，复用canonical Quality/Entry/Action计算；先比较名单，再附收益。不必先开发账户模拟器。

**固定规则纸面使用研究**：回答按明确方式使用名单的结果。必须冻结何时看榜、哪些状态可进入、入出价格、持有期、现金和成本。否则“Top-15回测”没有唯一含义。

**前瞻影子运行及人工日志**：回答规则确定后、真实可获得数据和实际使用中的效果。系统先写不可变选择与理由，未来结果成熟后另表追加。人工拒绝、等待、未成交也保留。

历史发现机制、时间外验证排除部分过拟合、前瞻检验实际可用性，三者不能互相替代。反复查看过的39/51日期及当前冻结研究结果不再冒充新OOS。按年份重新切开同一已见数据，也不能恢复未见状态。

### 3.2 数据合同与研究资格

每条记录至少为：`decision_date + available_at + symbol/entity_id + universe_version + metric_asof + filing/accession + Quality/Entry/Action + rank + selected + exclusion_reason + policy/code/config/input_hash`。

结果另表：`entry_time/price + exit_time/price + horizon + stock_return + benchmark_return + costs + MAE/MFE + label_status/reason`。后续财务结果保留其实际披露日，不能倒灌到历史决策特征。

必须覆盖：退市/更名/合并/拆股/分红、停牌、上市不足、缺失标签、财报发布可得时点、时区、价格/基准同窗。历史特征重建不能用后来重述的财报冒充当时已知；无法证明原始版本时披露限制。当前池近似不能消除幸存者/候选池漂移偏差；历史ETF不重建，已有归档优先，近似年份明确降级为诊断。

冻结数据若缺少某新指标，可计算字段覆盖与缺口，不能默认为完整，也不能用今天的指标补历史。只有明确既有数据无法回答的必要问题后才安排新回放；重计算优先Modal at2018cow前台执行并复用兼容检查点。

### 3.3 统计合同

- 主经济指标：每个决策日期等权的60交易日成本后超额；20/120d辅助。财务质量另看后续2/4个报告季度的经营延续，不能只用60d股价定义好公司。
- 报告均值、中位数、正超额比例、亏损尾部、按年/regime/行业/规模及最大贡献证券拆分；Precision@K按预注册成功定义计算，不能只数上涨股票。
- 可用同日Spearman Rank IC评价分数与未来超额的排序关联；ties、样本数与日期分布都披露。IC只是辅助，不能替代Top-15和风险指标。
- 以决策日期聚合并按日历块/市场阶段评估不确定性，同时给非重叠窗口、去掉最大贡献证券/年份敏感性；跨股票也有共同市场暴露，不能把数万行当数万个独立样本。
- 时间顺序开发/验证，训练可见的结果标签必须在验证开始前成熟；跨边界的持有窗口剔除或隔离。不采用随机打散股票日期行的训练测试切分。
- 所有实验入账，预先限定候选数、主指标、分箱、成本、区间方法；最终确认只比较已登记候选与基线。不能从一百张表只挑一张显著表。
- 预先确定最小有意义效果，再以有效日期/相关性评估检测能力；区间宽则记“证据不足”，不能把不显著直接当无效。

反复试验在有限历史中选最优规则会放大回测过拟合风险，参见原始研究：[Bailey等，The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。本方案据此限制候选并保留试验台账，不默认建设大规模调参平台。

## 4. 各层如何提升及评价

### 4.1 候选发现

先审查“根本没进入池”与“进池后没选中”的区别。记录发现→可交易映射→数据齐备→可评级→可行动→Top-15漏斗；每层给剔除原因与后续可观测表现。独立参考池须有当时可得的定义，不可事后只补上涨赢家。跨行业US Core拓展走既有独立方案，与阈值试验分开，不同时扩大股票池并宣称评分改进。

### 4.2 Company Quality与估值

优先研究：每股FCF及稀释、现金流持续性、营业利润与一次性收益区分、营运资本挤占、资本回报定义、周期正常盈利、估值增长假设。先做证据展示和覆盖审计，验证后才进评分。

经营评价包括：后续FCF保持为正比例、利润率下降、收入/营业利润延续、稀释恶化、偿债压力；明确指标定义及适用性。用A/B/C和同业务模式分层看是否有稳定区别，再在同质量层内比较估值与未来回报。质量强但股价回报差，可能是价格昂贵、风格不占优或观察期不匹配，应先归因。

### 4.3 Entry

分开比较：无Entry的同安全池、现有Entry筛选、同标的立即进入/等待确认。等待试验以首次观察事件为起点，冻结最长等待期、重复事件重置、失效条件和共同结束日；等待者未触发持现金，漏掉上涨也计入。主对照使用共同日历终点，触发后等持有期只作辅助，避免靠不同市场窗口制造优势。

评价等待的净收益差、最大不利波动、严重亏损、未触发比例、错过上涨和等待时间。若只能降低风险或研究噪音，就准确定位为风险/注意力工具；若无收益、风险、效率收益，则考虑简化，而非不断加指标。

### 4.4 Action排序和Top-15

先做无调参的漏斗归因：同安全池→Quality筛选→Entry→Action晋级→排序截断→日报S2。每个阶段既报告当前真实结果，也做固定输入的消融；阶段增量有路径依赖，不能把各段平均收益差解释为可相加的独立因果贡献。

检查Top1–5/6–15/16–30、行业/业务模式集中、赢家贡献和重复占位。5/10/15/30的K曲线只作为预登记容量诊断，不能事后挑最好K推广。最终是否加入行业上限或调整Q/E权重，由这些失败机制决定，不预设“降低Entry权重就一定更好”。

沿用配套合同的三层，但所有表都必须包括当前真实完整基线：

默认拟注册T2：每周固定截止时刻，报告实际发布后首个可交易常规开盘，合格名字各1/15名义份额，不足留现金，主持有60交易日，固定期限退出，15bps/边并报30bps/边。现金收益口径和基准统一；上市/退市与权益连续性异常不静默删除。详细规则见配套合同。

**每周重复60d队列不是有限资金账户**，不能连乘成年化或用队列尾部当账户最大回撤。只在用户需要检验具体资金部署方案时增加薄日历账本，明确重叠持仓、重复股票、可用现金与总暴露；该扩展不是选股研究前置条件。

随机K基线使用与当期相同数量和资格，固定种子，预登记重复次数，报告分布；成本/现金/进入时点与被测规则保持可比。配对基线不能用未经过相同资格约束的股票冒充“只差排序”。

## 7. 通过标准和失败后的处置

标准必须在实验前固定。以下是**拟注册建议，非已达成事实**：

- 工程门：关键算术/PIT/新鲜度/版本测试通过；正式样本无已知未来数据；名单parity差异为零或已解释并降级出正式范围。
- 经济改善门：可用60d净配对增量≥0.5个百分点作为初始最小有意义改善，同时预定95%时间块区间下界>0；严重亏损率的非劣界、尾部与成本压力要求在P0明确数值。若有效样本不够，不能降低门槛凑通过。
- 风险/工具门：若候选目标是减风险或省研究时间，事先登记主要目标和可接受收益损失上限，使用对应非劣与改善检验；不能收益失败后改称风险目标。
- alpha门：改善旧版与跑赢主基准是两个命题；对主基准的独立净超额及风险/集中度解释单独检验。没有这项证据就不宣称已验证alpha。
- 人工门：事先统一“值得深挖”的判定表与时间记录，采用相同研究预算、完整保留拒绝样本；未采真实日志就写UNKNOWN。

失败分支：数据不足→补最小必要证据；质量无分层→查指标口径/业务模式/重复计票；质量好而回报差→查估值/风格/期限；Entry无增益→查等待损失并考虑简化；池有效而Top-15差→查排序截断/集中/S2；纸面好而人工差→查信息表达、执行时差与偏离合同。每个失败都可止步，不强迫产出新策略。
