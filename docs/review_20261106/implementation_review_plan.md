## 1. 目标与范围

用最少工程投入，检验当前实际Top-15选择能力，覆盖上涨、下跌与恢复阶段；基于明确失败机制只研究一个最小改进。以历史回测验收，不等待前瞻观察。不建设自动交易、完整账户系统或大规模调参平台。

目标决策区间为2016年至最新可用月份；每种持有期只评价已经成熟的结果。当前已确认存在2022-01至2026-03的51个月度日期、33,276条冻结记录；更早及更新月份的数据资格尚未证明。当天优先完成可用范围及必要扩展；不能保证十年数据补齐与验收在当天结束，未完成时明确交付缺口而不缩短范围冒充通过。

## 3. 回测合同

- 全期间月末重建一次实际Weekly Top-15，准确称为“月度采样的周榜策略”；2020-02至2020-06及2022全年另作周频压力测试，结果单列。不能用月频代替Daily S2经济验证。
- 两张主表：全名单的选股诊断；仅最终`PRIORITY_REVIEW + ENTRY_READY`的固定使用诊断。后者每只1/15名义份额，空缺现金收益固定0。
- 使用信号可得之后的下一可交易常规开盘；固定期限退出。20/60/120交易日，60日唯一主指标；252日仅作标签合格时的辅助长期诊断。历史报告发布时间不可得时明确采用收盘后可得假设。
- 15bps/边成本，30bps/边压力测试；核实已有标签避免重复扣费。股票与QQQ同窗、同拆股/分红口径；无法统一则不能直接比较。
- 对照为当前基线、同资格池、固定种子随机同数量名单、QQQ；使用表同时列满额及相同部署比例QQQ。名单与使用表对照资格各自保持一致。
- 先报告年度和全期，再用当日QQQ相对SMA200、过去60d收益划分上行/下行/震荡：两者均正为上行、均负为下行，其余震荡。只用于分析，不改变生产regime；事件压力期为预先固定的解释分组。
- 报告净收益、超额、均值/中位数、正超额日期比例、期末亏损超过20%的比例、行业与证券集中、标签缺失。期末亏损不叫最大回撤；重叠队列不连乘成年化或账户净值。
- 缺失、退市、合并与假设收益单列；不得删除不利样本。早期使用冻结池/union时标明幸存者与主题事后选择偏差，不能宣称真实当年全市场PIT选股。

## 4. 如何控制试验和判定结果

先用已见2022–2026资料归因，登记一个候选，再揭示新增时期的候选对照。新增更早年份属于跨时期历史验证，不叫未来OOS。所有诊断、候选与失败结果入账，不为不同年份分别找最佳参数。

采用门槛在运行前冻结：60d日期等权净配对增量至少+0.5个百分点，中位数>0，成本压力下平均增量>0；全样本严重亏损率不增加；2022熊市、下行分组和2020急跌压力组平均收益不低于基线且严重亏损率不增加；剔除最大正贡献证券后平均增量仍>0。标签覆盖不得选择性改善。

> 用户随后将产品目标调整为“不必打赢QQQ，与QQQ接近即可”，并希望依理论和少量验证保持稳定参数，未选择具体容忍阈值。上述原候选协议保留原样；新增的1pp刻度只作参考、不作用户已批准的硬门槛，见[目标澄清](same_day_backtest/acceptance_update.md)。没有新增参数搜索或据此重写候选通过结果。

95%日期块区间下界>0才称本次历史证据支持稳定改善。块长覆盖60d标签对应的采样重叠；在预检阶段冻结种子和重采样次数。提供非重叠窗口敏感性，样本不足如实判为证据不足。仅点估计改善不默认替换生产。

候选比旧版好和跑赢QQQ分别判断；不通过则保留旧规则，交付诊断与工具。不能为满足当日目标降低门槛。数据近似未解决时，结论明确限制在近似候选池中。
