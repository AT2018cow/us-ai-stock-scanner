# 补齐实施方案：逐层归因、集中度与成本

状态：**D、E的剩余交付已补齐；A至F按约定范围完成。** 当前数值结论不等于未来收益保证，也不等于生产IEX历史数据已完整。原数据缺口和研究范围继续保留。用户无需选择硬性的QQQ容忍阈值，当前不以1pp宣布策略通过/失败，见[目标澄清](../acceptance_update.md)。

## 1. 理论合理的稳定参数，比穷举更适合本项目

资源允许做少量对照，真正的限制是有效历史样本与反复试验的过拟合风险。理论用于确定财务质量、现金流、偿债、估值和价格结构的经济含义；不能推导出SMA50偏离8%或Q/E权重60/40必然最优，也不能保证这些数值使收益贴近QQQ。

本轮保留现有可解释参数作为稳定基线，不新增组合搜索；只检验过已登记的一个年龄代理扣分候选，仍拒绝。Quality评分六支柱权重、A/B评级门槛和现有Entry阈值均不因这次诊断而调整。选股质量、价格位置与持有现金的作用应分开判断，不把所有差距都归咎于参数。

主名单SIP历史60d均值为3.74%，QQQ为4.23%，差距约0.49pp；按固定Ready使用规则收益为3.10%。后者对满额QQQ差距-1.13pp，可按同窗算术分解为：相同部署份额的证券选择差距约-0.43pp，加上现金/部署差异约-0.70pp。这个分解是基准算术，不是因果识别；不能把改变买入状态当作无风险补救。

因此可以把“中长期收益大体接近QQQ，同时保留财务筛选与风险解释价值”作为产品目标。当前均值提供了一些接近的证据，但不同年份、feed和现金规则差异明显，不能保证持续贴近或据此自动更改生产行为。

## 2. 完整阶段链条

阶段在选择时不读取未来收益。先用共享前置筛选，再调用正式Quality/Entry/Action函数；新计算的可研究池、状态和最终名单与冻结决策逐日期核对。

- 入场路径：eligible_all→quality_ab→quality_ab_ready→priority_review→priority_top15→fixed_usage。最后一步仅保留1/15名义份额，空缺现金0收益。
- 周榜路径：quality_ab→action_eligible_ab→weekly_top15。周榜包含Watch，不能强行接在Priority后面当作同一条纯过滤链。

每个阶段同时保留成员数、已观察数、缺失数和覆盖。下表只比较父子双方均完整的共同日期；每行日期数不同，差异不能相加。另有“仅已知结果子样本”的条件诊断，保留coverage并明确不是完整池估计，不用它宣布收益通过。

| SIP阶段 | 完整共同日期 | 子减父60d净收益 | 终值严重亏损比例差 |
| --- | ---: | ---: | ---: |
| eligible_all→quality_ab | 82 | -0.702pp | -3.342pp |
| quality_ab→quality_ab_ready | 117 | -0.666pp | -1.763pp |
| quality_ab_ready→priority_review | 117 | +0.372pp | +0.104pp |
| priority_review→priority_top15 | 117 | +0.479pp | +0.172pp |
| quality_ab→action_eligible_ab | 117 | -0.013pp | -0.019pp |

观察上，Quality与Ready筛选降低平均回报，也减少终值严重亏损。Priority晋级和最终排序并非完全无效：周榜从可研究池截断到15名，在117个完整共同日期上约增加0.40pp回报、降低1.87pp严重亏损比例。因此不能直接得出“删掉Entry或降低权重就会更好”。

IEX阶段对照见[阶段表](iex_monthly/stage_comparisons.csv)。其eligible→Quality只有36个完全共同日期，条件结果与完全样本甚至可能出现符号差异；应先看覆盖，不应为这种差异优化阈值。

## 3. 可核对的失败案例与反例

案例按每个阶段最差/最好日期固定抽取，共每组14例，不筛选只支持某个观点的案例。SIP实例：
