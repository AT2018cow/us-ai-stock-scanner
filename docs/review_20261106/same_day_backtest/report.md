## 1. 直接结论

当前规则在本次近似候选池中获得正的平均绝对收益，但**没有证明稳定跑赢QQQ**。主SIP月度样本中，60d全名单平均净收益约3.74%，QQQ超额约-0.49个百分点，95%日期块区间跨零；按约定只使用PRIORITY_REVIEW+ENTRY_READY且空缺留现金，收益约3.10%，超额约-1.13个百分点。收益单位是日期等权的持有期收益，绝非年化/账户收益。

2022压力样本显示部分相对防御价值，2020急跌后恢复样本则暴露等待与低部署比例的机会成本；不宜把全年或全样本一个均值当成适用于所有行情的结论。候选“取消财报年龄代理排序扣分”仅有很小点估计改善、依赖个别证券且风险门未通过，予以拒绝。

主SIP月度全名单增量95%区间[-0.239,+0.336]pp，固定使用[-0.215,+0.330]pp。均未达到+0.5pp门槛；中位增量为0；去掉最大正贡献证券SMCI后，主名单增量变为-0.083pp；2022月度全名单平均收益恶化约0.384pp。全样本终值严重亏损率也未满足非劣条件。**不采用候选，生产0.06代理扣分默认值保留。**

三项有界诊断的结论：

- 年龄代理：能够改变名单，但删除后的收益证据不足。财报年龄仍不能被解释为已确认的下一次财报日；报告保持“未核实”提示。
- Quality/Entry联合排序：SIP截面平均相关系数约0.16，不能认定两层完全重复；未据此擅自改60/40权重。
- Top-15截断：Priority边界平均联合分差约0.0048，年龄扣分0.06可显著改变边界；候选平均每日期换约1.09名，但换人没有带来达到门槛的改善。

这是一轮机制候选验证，不是全部财务/量价阈值的最优性证明。避免把候选不通过解释为所有财务指标无效，也不能因为参数可解释就称其有收益增量。
