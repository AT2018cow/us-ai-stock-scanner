# 当前 Top-15 的改进顺序与完整使用验证方案

状态：**研究设计草案，未运行新收益实验、未改变生产规则**。参考代码基线为`830702b73749c92be20f02a3463669f1b8e7dbd8`加本轮工作区正确性修复；修复源码身份见[实施验收](implementation_and_validation.md)。正式研究启动前须固定实际代码提交、配置、输入及方案哈希；Git提交号本身不能代表未提交工作区。

## 1. 先纠正结论范围

项目并非没有做过Top-15验证。准确的说法是：**本轮新增Entry对照是同日Quality A/B大池对比Ready子集，不是当前最终Top-15完整使用链路的验证。** 已有历史研究如下：

| 已有研究 | 已回答什么 | 仍不能回答什么 |
| --- | --- | --- |
| [M4，2026-10-15](../m4_paired_validation_20261015/m4_validation_report.md) | 旧版本Top-15、39日期、v1/v2配对、年度/regime与敏感性 | 当前修复版、当前Daily保留机制及真实人工使用；M4报告中的旧生产默认声明不能覆盖现行配置 |
| [成长进攻研究，2026-10-17](../growth_compounder_offense_validation_20261017/report.md) | 提高成长暴露的C2/C3曾改善部分收益指标，但恶化下跌/熊市严重亏损比例；没有候选通过全部门槛 | 不能只取收益较好的表格即推广；也不能原样重开已否决候选 |
| [名单稳定性，2026-11-05](../top15_stability_validation_20261105/report.md) | 13份日报上的名单稳定性，以及51个月度截面对B0/S3的经济诊断 | S2的完整经济验收：报告明确S1/S2的G4没有评估；不能用S3结果替代当前S2 |
| [本轮Entry对照](evidence/entry/README.md) | 当前Quality/Entry计算下，大池到Ready子集没有稳定正收益增量 | 最终排序、名单截断、日报惯性、等待后确认及人工挑选效果 |

当前`assign_action_priorities_v2`在Priority Review内采用Quality 0.60 + Entry 0.40，并有等级及风险修正；`select_daily_attention`在提供昨日名单时采用S2：即时进入、软退出宽限一天、硬损坏立即移除。周榜、日报、Offense/Radar、降级告警的角色不同。`Top-15`是注意力上限，不能把所有状态一律当作买入。

## 2. 改进顺序

### P0：建立当前最终名单的可信基线

先冻结修复后的完整链路，核对实际名单与重建名单的成员、次序、状态、宽限理由、剔除原因。所有收益标签单独附加。历史数据是近似候选池，且旧标签存在已记录缺陷；覆盖不足必须写UNKNOWN/UNAVAILABLE，不做收益导向填充。

不能因为当前Entry大池对照不好，就认定权重应从40%改为某个更小数字。Entry同时影响状态、晋级和排序，简单改权重未必换人。首先统计Top-15→Top30边界的真实换人、分数饱和、行业/成长/估值集中，以及少数大赢家贡献。

### P1：把Entry作为风险/结构解释与收益假设分别评价

保留数据不可用、趋势损坏等明确安全边界。分别看“价格过热”“健康回调”“趋势确认”能否减少不利波动、避免过度追高、提高后续收益或减少研究噪音；不要要求它们都通过同一个平均收益指标。

若基线诊断支持机制，最多登记**一个**新排序候选：同一安全合格池中，主要按已冻结的Quality/估值证据排序，Entry作为次序辅助或等待解释。它只是待验证假设，不能直接替换生产；状态仍明确区分Ready与Watch，不把等待状态升级成买入结论。

另设**同一标的的入场时机研究**：首次进入观察名单后，立即纸面进入与等待现有确认条件再进入比较。等待期限、失效规则和现金机会成本事先固定；未确认/价格先上涨也必须计入。该研究能补足“不同股票分组比较”无法回答的等待价值，但不能证明实际人工交易的因果收益。

### P2：提高长期公司与估值解释

优先审查每股现金流、稀释、增长持续性、周期高点盈利及正常化估值；数据/业务模式不适用时明确标记。当前已有盈利±20%敏感性，后续只有在可信输入覆盖允许时扩充。短期涨幅不能成为财务质量加分理由。银行/REIT等继续遵守专业会计验证边界。

成长进攻方向已有收益/风险权衡证据，应保留独立观察层，不能因为历史涨得更多便挤掉主榜防守语义。财报年龄不是下一次业绩日期；事件日期未知时保留未知，不建立“即将财报已确认”的假象。

### P3：根据真实反馈改进人工工作台

先使用已有复核日志记录研究耗时、值得深挖比例、拒绝原因、重复占位和升级后失效。日报强调变化，周榜固定研究节奏。已有S2稳定性机制不再重复造轮子；应先验证它是否仅减少视觉换人，还是也改善研究效率而不延迟重要风险。

## 3. 三层验证与明确的使用合同

### 层A：名单研究价值（所有实际展示状态）

每周取一份固定时点生成的最终Weekly Top-15，保留真实成员和状态；日报另按真实时间序列验证状态变化与S2保留。已发布快照直接读取manifest中的daily_symbols/weekly_symbols，不以事后排序替代。当日没有新名单时记缺失/失败，不借用未来名单。

比较对象：

- 同日相同安全资格的Quality A/B池，回答压缩到15只是否提高研究精度。
- 同池随机K只，K等于当期实际名单规模，固定随机种子并报告随机分布；避免“随便选15只也一样”。
- 行业/规模匹配的同日对照只作辅助，匹配仅用当时已知字段，报告匹配失败率。ETF源标签不能代替行业分类。

记录20/60/120交易日股票回报、同窗QQQ超额、期间最大不利/有利波动、严重亏损率、每周新增与重复占位、值得深挖比例及研究耗时。SPY作为固定辅助市场参照，不能在看结果后切换主基准。剔除未来收益标签缺失行时，必须报告数量/原因/名单占比，不能仅展示幸存者。

这里把全名单收益当作**选股诊断**，不称为按Action实施的交易收益。

### 层B：固定纸面使用规则（默认建议）

这是可复核的统一基准，不读取账户，不提交订单，不把账户NAV模拟变成前置条件：

| 项目 | 拟冻结规则 |
| --- | --- |
| 决策节奏 | 每周固定一次，取指定截止时刻已经完成并可读的正式Weekly名单 |
| 可进入部分 | 仅最终名单中Action=PRIORITY_REVIEW且Entry=ENTRY_READY，且无完整性阻断；Watch/Hold/降级告警不自动进入 |
| 观察权重 | 每个合格名字占1/15名义份额；不足15份保留现金，不把少量名字重新放大到满仓 |
| 入场 | 报告实际发布时间之后的第一个可交易常规开盘；历史重建必须明确“收盘后可得”的假设，禁止用生成前的价格 |
| 期限 | 主指标60交易日，20/120作为预先登记的辅助诊断；不在看结果后换主期限 |
| 退出 | 本组固定期限退出；期间Action变化作为诊断记录。若另研究硬风险提前退出，须另立固定规则并同时用于所有对照 |
| 未成交/停牌/退市 | 入场不可用则该份额持现金并记录原因；持有后的退市/重组不能静默删掉。未解决权益连续性则停止相应正式结论，保留缺失/保守情景并披露 |
| 成本 | 可沿用既有15bps/边基线，另报30bps/边敏感性；是研究假设，不是IEX数据可证明的真实成交成本 |
| 价格口径 | 股票和基准必须同一入出时点、拆股与分红口径。只有价格回报时双方都用价格回报并标清，不能一方含分红一方不含 |
| 现金与比较 | 事先固定现金回报口径；同时报告满额QQQ与相同已部署份额QQQ，区分证券选择与持有现金造成的差异 |

**每周队列是独立观察单元，不是可以同时满额投入的多个真实账户。** 重复股票/重叠60日窗口不得当作独立证据；这些队列的平均收益不得连乘成年化或NAV。若未来需要真实账户效果，应单独建立有限资金、重叠暴露、现金和实际交易的日历账本。

主比较同时报告：

1. 当前完整纸面使用合同的净回报与QQQ/安全合格池。
2. 若有候选，候选相对当前完整合同的同日配对增量；“较旧版少亏”不能自动叫有正alpha。
3. 风险/成本/空缺份额敏感性，按年份、当时可知regime、行业/证券集中度和市场episode拆分。事后定义的牛熊区间只作解释，不反馈为当时门禁。

### 层C：真实人工增量

在看到未来价格之前，记录看到名单/报告的时间、选择深挖/跳过/继续等待、拒绝原因、选择时间、可接受的研究条件和耗时。真实交易若存在可作为另外一张人工执行结果表，不与系统纸面合同混合。

可在纸面研究任务中按周内、行业/难度分层随机分配“现有工作流”与“完整Action List+报告”，统一复核预算，比较耗时和有价值研究命中；同一个案例不要先看一版再看另一版，避免记忆污染。只观察人工挑中的股票更好不能直接归因给系统，必须保留被拒绝/等待的全样本。

## 4. 冻结、统计与验收

- 每次保存代码/config/source/universe/policy哈希；Quality、Entry、Action排序、日报保留、报告/人工使用规则分别有版本。历史快照不改写，修复版重建另存独立输出根。
- 先冻结一个主指标与有限候选。当前39/51日期已被反复查看，继续使用只能叫回溯诊断；后续真实不可变快照按时间自然成熟，不能把尚未公开的未来结果填进去。
- 先按决策日期等权，区分重复股票/事件；置信区间按日历块或市场episode重抽样，并报告非重叠标签的敏感性。周度60日窗口约覆盖12周，不能把每周重叠观测作独立样本进行普通t检验。块长度、候选数量和所有试验记录事先固定。
- 建议的初始“经济改善”实用门槛可登记为60日净配对增量至少+0.5个百分点，但这是**待正式预注册的建议值**，不是已经证明可达到的目标。还须看区间、跨期稳健性、严重亏损及成本敏感性；阈值不能在结果出来后降低。
- “可靠正alpha”需独立/前瞻证据支持对主基准的净超额，同时审查集中度、风险暴露与多次试验。若区间过宽，结论是证据不足；不能因为某个平均数为正就宣布通过。
- “人工辅助有效”可以由更短复核耗时、更高有效研究比例和更完整的风险识别支持，必须与“已验证超额收益”分别写结论。
- 前4–8周适合验收采集和操作流程；6/12个月可安排阶段复核，但**时间到了不等于样本足够**。有效日期、标签成熟、市场状态覆盖和区间精度才决定能说什么。

反复从同一有限历史中选出最好规则会放大假阳性；方案采用有限候选、完整试验台账及新前瞻证据，依据见 Bailey等人的原始研究 [The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。不因此默认建设复杂模型搜索平台。

## 5. 下一步的具体交付顺序

1. **基线身份与决策parity**：固定当前实际版本，验证published名单与重建名单；日频/历史状态不足的部分明确不可比。输出名单diff、失效理由、输入覆盖及哈希。
2. **当前Top-15基线报告**：复用已有冻结数据，分别输出静态月度名单诊断、真实日频使用诊断；不能拿月频横截面冒充完整S2日频经济验证。不新增昂贵全量回放，除非写清既有证据无法回答的具体缺口。
3. **前瞻纸面使用与人工日志**：在冻结使用合同后归档选择与计划，再等收益自然成熟。结果表与原快照分开，不能回写官方决策。
4. **最多一个机制候选**：只有基线失败归因明确后才实现，先做同日无收益换人预检，再做已登记的配对验证；没有可信机制时记录NONE。

当前已可用的`review_selection_utility.py`只覆盖注意力统计和Quality池/Entry子集对照；`evaluate_top15_turnover_stability.py`覆盖已有稳定性研究。它们都**不等于本方案全部实现**。本页是具体研究合同草案，不宣称完成了新的Top-15经济验收，也不自动授权历史数据重建、生产推广或真实交易。
